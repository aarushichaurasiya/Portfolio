QBADS — Quantum–Blockchain Anomaly Detection System

Research Prototype
QiskitQSVM / QNNPythonReactTypeScriptTailwind CSSBlockchain

A hybrid research and engineering prototype combining Quantum Machine Learning with blockchain-based auditability for transparent anomaly detection in financial transactions. The system is designed as an end-to-end demonstration from transaction ingestion to detection, immutable audit logging, and human-interpretable monitoring.

  • Quantum anomaly detection layer exploring QSVM / QNN models with quantum-state feature encoding and simulator or backend inference
  • Classical–quantum backend orchestration with preprocessing, REST APIs, and latency/performance tracking
  • Permissioned blockchain audit layer for timestamped anomaly events and traceable detection outcomes
  • React + TypeScript dashboard for transaction monitoring, anomaly scores, risk classification, model metadata, and audit inspection

Current status: system architecture defined, frontend dashboard scaffolded, backend and quantum pipelines under active development, and blockchain integration in progress. This is an academic/experimental prototype rather than a production financial system.
